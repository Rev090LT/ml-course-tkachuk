# 🏠 Датасет «House Prices: Advanced Regression Techniques»

## 📌 Общие сведения
- **Соревнование:** [Kaggle: House Prices - Advanced Regression Techniques](https://www.kaggle.com/c/house-prices-advanced-regression-techniques)
- **Оригинальный источник:** Ames Housing Dataset, составленный профессором Дином Де Коком (Dean De Cock, Truman State University, 2011)
- **Тип задачи:** Supervised Learning — Обучение с учителем, регрессия (Regression)
- **Целевая переменная:** `SalePrice` — цена продажи жилой недвижимости в городе Эймс (штат Айова, США) в долларах США.

---

## 📊 Структура и размерность данных
- **Обучающая выборка (`train.csv`):** 1460 строк (наблюдений), 81 столбец (включая идентификатор `Id` и целевой столбец `SalePrice`).
- **Тестовая выборка (`test.csv`):** 1459 строк, 80 столбцов (целевой столбец отсутствует, предназначен для сабмита).
- **Всего признаков:** 79 содержательных признаков:
  - **Числовые признаки (Numerical):** 36 признаков (площади, количество комнат, ванных, год постройки, размер гаража и т.д.)
  - **Порядковые признаки (Ordinal):** качественные оценки (например, `ExterQual`, `BsmtQual`, `KitchenQual` со шкалой от Poor до Excellent)
  - **Номинальные категориальные признаки (Nominal):** категориальные параметры без естественного порядка (`MSZoning`, `Neighborhood`, `SaleType` и др.)

## 🎯 Статистика целевой переменной (`SalePrice`)
- **Минимальное значение:** $34,900
- **1-й квартиль (25%):** $129,975
- **Медиана (50%):** $163,000
- **Среднее значение:** $180,921
- **3-й квартиль (75%):** $214,000
- **Максимальное значение:** $755,000
- **Асимметрия (Skewness):** ~1.88 (выраженная правосторонняя скошенность, длинный правый хвост)
- **Эксцесс (Kurtosis):** ~6.51 (тяжёлые хвосты распределения)

> **Вывод для моделирования:** Для стабилизации дисперсии остатков и приведения распределения к нормальному виду применяется логарифмическая трансформация $y_{log} = \ln(1 + \text{SalePrice})$ (`np.log1p`).

## 🔍 Группы признаков и их смысловое описание

### 1. Качество и состояние
- `OverallQual`: Общая оценка качества материалов и отделки дома (от 1 до 10). Является самым сильным предиктором стоимости.
- `OverallCond`: Общая оценка состояния дома (от 1 до 10).
- `ExterQual`, `ExterCond`: Качество и состояние наружной отделки.
- `BsmtQual`, `BsmtCond`: Высота и состояние фундамента / подвала.
- `KitchenQual`: Качество кухни.
- `GarageQual`, `GarageCond`: Качество и состояние гаража.
- `FireplaceQu`: Качество камина.

### 2. Площади (Area / Square Footage)
- `GrLivArea`: Жилая площадь над уровнем земли (кв. футы). Ключевой фактор размера дома.
- `TotalBsmtSF`: Общая площадь подвала (кв. футы).
- `1stFlrSF`, `2ndFlrSF`: Площадь 1-го и 2-го этажей соответственно.
- `LotArea`: Площадь земельного участка (кв. футы).
- `GarageArea`: Площадь гаража.
- `WoodDeckSF`, `OpenPorchSF`, `EnclosedPorch`, `3SsnPorch`, `ScreenPorch`: Площади открытых и закрытых веранд, террас.

### 3. Временные характеристики
- `YearBuilt`: Год постройки дома (от 1872 до 2010).
- `YearRemodAdd`: Год реконструкции / ремонта (если ремонта не было — совпадает с годом постройки).
- `YrSold`: Год продажи (2006–2010).
- `MoSold`: Месяц продажи (сезонность).
- `GarageYrBlt`: Год постройки гаража.

### 4. Локация и зонирование
- `Neighborhood`: Район расположения дома в пределах Эймса (25 уникальных районов с разным уровнем достатка).
- `MSZoning`: Зона использования (жилая низкая плотность RL, высокая плотность RH, коммерческая C и др.).
- `Condition1`, `Condition2`: Близость к железным дорогам, паркам, магистралям.

### 5. Инженерные коммуникации и удобства
- `FullBath`, `HalfBath`: Количество полных и половинных ванных комнат над землей.
- `BsmtFullBath`, `BsmtHalfBath`: Количество ванных в подвале.
- `BedroomAbvGr`, `TotRmsAbvGrd`: Количество спален и всех комнат над землей.
- `Fireplaces`: Количество каминов.
- `GarageCars`: Вместимость гаража в автомобилях.
- `PoolArea`, `PoolQC`: Бассейн и его качество.

## 🛠️ Особенности предобработки
1. **Смысловые пропуски (`NA`):** Во многих признаках значение `NA` означает не отсутствие информации, а физическое отсутствие объекта (например, отсутствие гаража, подвала, камина или бассейна). При импорте в Pandas они считываются как `NaN`, поэтому их необходимо преобразовать в строку `"None"` для категорий и в `0` для численных характеристик.
2. **Случайные пропуски:** `LotFrontage` (ширина фасада участка) восстанавливается через групповую медиану по району `Neighborhood`.
3. **Выбросы:** Согласно рекомендациям автора датасета Dean De Cock, дома с жилой площадью `GrLivArea > 4000` кв. футов и ценой `SalePrice < $300,000` являются нетипичными сельскохозяйственными объектами и подлежат исключению из обучающей выборки.
4. **Конструирование признаков (Feature Engineering):**
   - `TotalSF` = `TotalBsmtSF` + `1stFlrSF` + `2ndFlrSF` (полная площадь)
   - `TotalBath` = `FullBath` + 0.5 * `HalfBath` + `BsmtFullBath` + 0.5 * `BsmtHalfBath` (общее число санузлов)
   - `HouseAge` = `YrSold` - `YearBuilt` (возраст дома на момент продажи)
   - `RemodAge` = `YrSold` - `YearRemodAdd` (лет с момента реновации)
   - `OverallQual_TotalSF` = произведение качества на общую площадь.
